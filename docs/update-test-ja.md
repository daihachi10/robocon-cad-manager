# 0.1.6から0.1.7への自動更新テスト

このPCには0.1.7を手動インストールせず、0.1.6を残しています。次の操作でアプリ内の更新機能を確認できます。

1. SolidWorksの文書を保存して閉じ、アプリで取得・送信などの処理が完了するまで待ちます。
2. インストール済みの「高専ロボコン CAD 管理」を起動します。
3. 起動時に更新の案内が出れば内容を確認します。出なければ「その他」→「更新を確認」を押します。
4. 新しいバージョンが0.1.7であることを確認し、「はい」を押します。
5. ダウンロードとサイズ・SHA-256の検証が終わると、インストーラーが起動し、アプリが終了します。
6. インストーラーの案内に沿って上書きします。Git・Git LFSの公式配布物はインストーラーに含まれています。動作する同梱Git LFSがすでにある場合は再導入を省略します。
7. 完了後にアプリを起動します。設定したリポジトリ、作業フォルダ、名前・メールが残っていることを確認します。
8. 「その他」→「更新を確認」で「すでに最新版です」と表示されることを確認します。

今回の配布インストーラーは約65 MiBになるため、以前の約2 MiBの版よりダウンロードに時間がかかります。

## 結果の記録

- [ ] 更新の案内が表示された
- [ ] 0.1.7をダウンロードできた
- [ ] インストーラーが起動して、元のアプリが終了した
- [ ] 上書き後にアプリを起動できた
- [ ] リポジトリと作業フォルダの設定が残っている
- [ ] 「すでに最新版です」と表示された
- [ ] Git LFSのロック状態を取得できた
- [ ] 他の人が編集中のファイルで警告が出て、開いてローカル保存できた

SolidWorks自体が文書を読み取り専用で保持している場合は、保存後にアプリから開き直してください。他の人のロックを強制解除する機能はありません。Git LFSが送信を拒否した場合は、相手に作業終了とロック解除を確認します。

問題があれば、どの番号の手順か、エラーメッセージ、発生時刻を記録してください。パスワードや認証情報は記録しません。
