# 0.1.16 検証記録

## 変更内容

- 「保存して送信」を add、commit、push の3段階で表示する。
- 各段階のコマンド、終了コード、標準出力、エラー、正常・異常の結果をログ欄へ追記する。
- 処理状況ウィンドウの進捗バーを、段階に合わせて 0/3 から 3/3 まで進める。
- 失敗時は、それ以前に成功した段階のログを保持したまま処理状況ウィンドウを残す。
- 更新、最新状態取得、複製、LFS設定、更新確認、.gitignore取得でも完了結果をログへ反映する。
- ログ・コマンド・進捗の更新時にウィンドウを即時再描画する。

## 検証項目

- Release構成のビルド。
- add、commit、pushの開始・完了通知が順番どおり発生すること。
- 進捗バーが段階に合わせて進むこと。
- コマンドと正常終了ログが画面へ表示されること。
- エラー表示で、それ以前の正常ログが消えないこと。
- 既存のGit設定、フォルダー表示、DPI、ドラッグ＆ドロップ回帰テスト。
