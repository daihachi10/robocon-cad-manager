# 0.1.9 フォルダ表示と変更検出

一覧をフォルダ単位に変更しました。フォルダをダブルクリックして中へ移動し、ファイル名だけを表示します。戻る・進む・上の階層へ移動するボタンと、現在位置の表示を追加しました。拡張子の絞り込み中もフォルダへ移動できます。

フォルダには配下の変更件数を表示し、チェックで配下の変更をまとめて選択できます。チェック状態は表示中のフォルダから独立して保持します。変更のないファイル・フォルダに送信チェックは表示しません。削除されたファイルの親フォルダも、削除内容を送信するまで一覧からたどれます。

新しいフォルダの変更が自動チェックされなかった原因は、Gitが未追跡フォルダを1件にまとめて返していたことです。`--untracked-files=all` を指定し、個別のファイルを取得するよう修正しました。改名時のNUL区切りデータも正しく読み飛ばします。

ローカル更新は一度に1つとし、処理中の追加通知は次の更新にまとめます。取得失敗時にチェック状態を消さず、設定対象を変更した後に古い結果が表示されることも防ぎます。常時タイマーや定期通信は追加しません。

同梱Gitでの試験には、入れ子・日本語・空白を含むパス、既存ファイルの変更、新規フォルダ、追加・削除、空フォルダ、仮ファイル除外、チェック保持を含みます。別のテスト用ウィンドウで、実際のListView、ダブルクリック、戻る・進む、フォルダ選択、100～200%の配置、Windowsの再帰ファイル通知を検証します。

インストール済みのアプリは変更せず、ビルドとテスト用環境で検証します。
