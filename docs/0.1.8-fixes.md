# 0.1.8 修正内容

## 設定の氏名・メールとGitの変更記録

以前の版では、アプリの設定を保存してもGitの氏名・メールへ反映する処理が「複製」時だけでした。既存フォルダを登録した人や、複製後に氏名・メールを変更した人は、Gitの設定が未反映になることがありました。

0.1.8では、次のタイミングで対象リポジトリの `user.name` と `user.email` を更新します。

- 複製済みフォルダに対して設定を保存したとき
- 新しい変更を記録して送信する直前
- リポジトリを複製した直後

書き込んだ設定はGitから読み戻して確認します。空欄は日本語で入力を案内し、書き込みに失敗した場合は変更の記録を始めません。PC全体のGit共通設定は変更しません。

利用者は更新後に「その他」→「設定」で「変更記録に使う氏名」と「変更記録に使うメールアドレス」を確認し、「保存」を押してください。コマンドを入力する必要はありません。すでにアプリへ保存済みの内容も、次の変更保存・送信時に反映されます。

## 更新ダウンロード

Git・LFSを同梱して約65 MiBになったインストーラーの取得に合わせ、受信待ちを10秒から120秒に変更しました。更新情報だけの取得は30秒です。

受信サイズの問い合わせを繰り返す方式から、64 KiBの固定バッファーで読み、その都度一時ファイルへ保存する方式へ変更しました。ファイル全体をメモリに保持しません。途中で失敗したファイルは削除します。サイズとSHA-256の一致を確認した後に実行可能な更新ファイルとして扱います。

旧版の更新機能でタイムアウトが続く場合は、次のリンクから新しいインストーラーを取得して上書きしてください。

[最新版のインストーラー](https://github.com/daihachi10/robocon-cad-manager/releases/latest/download/RoboconCadManagerSetup.exe)

## 検証

テスト用のローカルリポジトリで、氏名・メールが未設定の状態からGitの終了コード128を再現し、修正後の保存・送信成功を確認しました。既存フォルダへの設定反映、変更後の氏名・メール、共通設定の保持、空欄の拒否も検証対象です。

このPCには修正版をインストールしません。更新機能の試験ではダウンロード・検証だけを行い、インストーラーは起動しません。
