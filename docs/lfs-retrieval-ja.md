# 大容量のSolidWorksファイルが 0 KB・開けない場合

Git LFSで管理されているCADファイルは、Gitの通常データには本体ではなく小さな案内ファイル（LFSポインタ）が保存されます。本体の取得に失敗すると、一覧では **「大容量ファイルの本体未取得」**、容量欄では **「LFS未取得」** と表示されます。この状態ではSolidWorksで開けません。

## 復旧方法

1. ネットワークに接続し、GitHubへサインインできる状態にします。
2. アプリの **その他 → 大容量ファイルを取得** を選びます。
3. 完了後、一覧を更新して「LFS未取得」が消えたことを確認します。
4. ファイルを開きます。ファイルを直接開いた場合も、アプリは先にそのファイルの本体を取得します。

取得できない場合は、処理画面の出力を確認します。認証失敗ならGit Credential ManagerでGitHubにサインインし、接続失敗ならネットワークとリポジトリの権限を確認してから、同じ操作を再実行してください。

## 0.1.22からの動作

- 複製後にLFS本体を取得する。
- 「更新」の後にもLFS本体を取得する。Gitの履歴に変更がなくても、ポインタだけ残った状態を修復する。
- LFSポインタを0 KBのCADファイルとして表示しない。
- LFSの本体が取得できなかった場合は、通常の更新を成功として扱わず、ログを残す。

アプリは「LFS未取得」のファイルを勝手に空ファイルへ置換したり、削除したりしません。GitHub上にLFS本体そのものが存在しない、LFS容量・帯域の上限に達した、またはリポジトリへの権限がない場合は、リポジトリ管理者側の対応が必要です。
