# 0.1.15 検証記録

## 変更内容

- ファイル絞り込みを「SolidWorksファイル」「すべてのファイル」「パーツ」「アセンブリ」「図面」の順に変更し、「SolidWorksファイル」を既定にした。
- GitHubからの更新、保存して送信、複製、最新状態の取得、LFS設定、アプリ更新確認、`.gitignore`取得中に処理状況ウィンドウを表示する。
- 処理状況ウィンドウには進捗バー、現在の処理、デバッグ用コマンド、標準出力、終了コード、エラーを表示する。URL内の認証情報はコマンド表示から伏せる。
- 成功時は処理状況ウィンドウを閉じて完了通知を表示する。失敗時はウィンドウを残し、ログを確認してから閉じられるようにした。
- 設定、履歴、入力画面をDPIに合わせて拡大し、所有ウィンドウ中央へ適切な大きさで表示する。コントロールの高さを増やし、`Yu Gothic UI`の文字切れを防ぐ。

## 検証項目

- Release構成のビルド。
- 既定の絞り込みで通常ファイルを表示せず、3種類のSolidWorksファイルを表示すること。
- 5種類の絞り込みとフォルダー移動。
- 処理状況ウィンドウが処理中に親画面を無効化し、成功・失敗後に正しく復帰すること。
- 100%、125%、150%、200% DPIで一覧とダイアログの文字・ボタンが重ならないこと。
- 既存のGit、フォルダー監視、ドラッグ＆ドロップ回帰テスト。
