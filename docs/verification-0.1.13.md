# 0.1.13 検証記録

## 変更内容

- Git LFS のロック機能をリポジトリごとの設定で既定無効にした。
- 既存設定には `lfsLockEnabled` が存在しないため、更新後は自動的に無効になる。
- 無効時はロック一覧の通信、`git lfs lock`、`git lfs unlock` を実行しない。
- CAD ファイルはロックの成否を待たずに開ける。編集中の列には「ロック機能は一時的に無効です」と表示する。
- 必要になった場合だけ「その他」→「設定」→「LFSロック機能を使用する」で再有効化できる。

## 実行した確認

- Release 構成でビルドする。
- 既存の統合テストとフォルダーブラウザーテストを実行する。
- 設定ファイルにロック設定がない場合、既定値が無効になることをソースレビューで確認する。
- 無効時の更新・ファイルを開く処理に Git LFS コマンドが到達しないことを確認する。

## 注意

この変更は Git LFS のロックを停止するものであり、過去に Git LFS へ登録済みのファイル本体を通常の Git ファイルへ変換するものではありません。LFS ポインターだけがある古いリポジトリを初めて複製する際は、そのファイル本体を取得するために Git LFS が必要です。履歴を含めて LFS を廃止するには、リポジトリ全体の別途移行が必要です。
