# 0.1.1 アイコン・スタートメニュー修正

- 指定の `assets/app.svg` の形状と色を維持したICOを埋め込み。
- ICOに16/20/24/32/40/48/64/128/256pxの透過画像を収録。
- EXE、起動中ウィンドウ、インストーラー、ショートカットで同じアイコンを使用。
- アプリとショートカットのAppUserModelIDを `RoboconCadManager.Desktop` に統一。
- スタートメニューの名前を「高専ロボコン CAD 管理 (RoboconCadManager)」へ変更。
- スタートメニューのピン留めは利用者が手動で行う。
- 更新時、既存GitとLFSがあれば再取得・再インストールを省略。
- パッケージ作成時にCMake・EXE・指定バージョンの一致を検証。
- Visual StudioとNMakeの出力先の違いに対応。失敗時は配布処理を停止。
